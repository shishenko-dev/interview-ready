# Interview Ready

Interview Ready — локальный штаб подготовки к собеседованиям. Пользователь
добавляет подтверждённые навыки и полный текст вакансии, после чего получает:

- карту подтверждённых совпадений;
- список требований, которые ещё нечем доказать;
- вероятные вопросы работодателя;
- последовательность подготовки;
- тренажёр ответа с прозрачной оценкой структуры.

Продукт не придумывает опыт, не подменяет кандидата и не обещает приглашение.
Оценка показывает только пересечение распознанных требований с тем, что сам
пользователь указал в качестве доказательств.

## Для кого

- для соискателя, который теряется между несколькими вакансиями;
- для начинающего специалиста, которому трудно объяснить свой проект;
- для карьерного консультанта, которому нужен единый рабочий экран;
- для человека, который хочет тренировать ответы по конкретной вакансии.

## Основной сценарий

1. Нажмите «Добавить вакансию».
2. Укажите компанию, роль и, при наличии, ссылку.
3. Вставьте только подтверждённые навыки, проекты и результаты кандидата.
4. Вставьте полный текст вакансии.
5. Изучите совпадения и пробелы.
6. Откройте тренажёр, напишите ответ и улучшите его по подсказкам.

## Что означает оценка

Оценка соответствия строится по открытым правилам:

- какие технические темы распознаны в вакансии;
- какие из них явно встречаются в описании опыта;
- есть ли в доказательствах числа и проверяемый результат.

Это ориентир для подготовки, а не решение о найме. Перед отправкой ответа
пользователь обязан проверить факты самостоятельно.

## Технологии

- TypeScript — язык программы со строгой проверкой типов;
- React — библиотека для интерфейса;
- Cloudflare D1 — облачная база данных на основе SQLite;
- Drizzle — описание структуры базы и миграций;
- встроенный `node:test` — автоматические проверки логики.

## Запуск для разработки

Требуется Node.js 22.13 или новее и pnpm.

```powershell
pnpm install
pnpm dev
```

Проверки и сборка:

```powershell
pnpm test
pnpm lint
pnpm build
```

Изменение структуры базы:

```powershell
pnpm db:generate
```

Структура базы изменяется только миграциями из каталога `drizzle`. Серверный
код не создаёт таблицы во время обычного запроса.

## Ограничения демонстрационной версии

- распознавание требований основано на словарных правилах;
- система не проверяет достоверность введённых пользователем фактов;
- нет автоматической отправки откликов и сообщений работодателям;
- нет записи голоса: тренажёр оценивает введённый текст;
- демонстрационные данные вымышлены.
